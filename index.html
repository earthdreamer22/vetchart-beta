병원 안에 두는 차트

클라우드가 아니라 병원 서버 PC에 데이터가 있습니다. 인터넷이 없어도 진료·수납이 되고, 매일 자동으로 백업합니다. 모든 PC 화면에 지금 연결된 서버가 보입니다.

SOAP 차트

주관·객관 소견, 평가·진단, 처방·처치를 한 화면에. 분류별 문진 템플릿, 체중으로 자동 계산되는 처방 용량, 과거 진료·바이탈 추이·검사 결과를 옆에서 바로 봅니다.

영상 뷰어

X-ray·초음파 영상(DICOM)을 차트 안에서 바로 봅니다. 확대·밝기 조절·반전·회전, 초음파는 mm로 길이를 잽니다. X-ray 촬영 오더도 차트에서 보냅니다.

수납·일 마감

보호자 단위 청구서, 분할 결제·취소·환불, 미수와 미수납 구분, 여러 PC에서 동시에 열어도 맞는 금액. 지난 날짜의 수납 내역도 대시보드에서 바로.

예방관리

종합백신·광견병·심장사상충·외부기생충의 다음 예정일을 자동 계산하고 예약 목록에 올립니다.

바로 쓰는 기본값

진찰·처치·검사·마취(체중별) 등 기본 수가표와 문진 템플릿이 들어 있어 금액만 고쳐 쓰면 됩니다. 진료비 세부내역서·보험 청구용 서류도 A4로 바로 출력합니다.

언제든 내 자료를 꺼내기

보호자·동물·진료·청구·결제·예방접종 전체를 엑셀에서 열리는 파일로 언제든 내보냅니다. 그 파일 그대로 다시 가져올 수도 있습니다.

반복 업무 자동화

마약류 투약 보고 파일 작성, 부가세 신고 자료 정리, 진료 통계 보고서, 관심 분야 최신 논문 요약 메일처럼 매번 손이 가던 일을 AI가 정리해 드립니다.

치료 사례와 병원 소식으로 블로그 글·카드 이미지·쇼츠 영상 초안을 만들고, 홈페이지 진료 안내도 말 한마디로 고칩니다. 발행은 원장님이 확인한 뒤에.

상담 통화를 병원 PC에서 글로 바꾸고(개인정보는 가림) 고객응대 매뉴얼 수정안을 만듭니다. 원장님이 승인하면 모든 PC에서 최신 매뉴얼을 봅니다.

베타 참여 방법

신청서를 확인한 뒤 적어 주신 이메일로 설치 안내를 보내 드립니다.

참여 신청

[베타 참여 신청하기] 양식에 동물병원 이름·사업자등록번호(개설자 확인용)·성함·휴대폰·이메일, 지금 쓰는 차트와 DB 파일 형식을 적어 주세요. DB 형식을 모르시면 '모르겠음'을 고르시면 됩니다.

설치 안내

확인 후 메일로 설치 방법을 안내해 드립니다. 서버 PC 한 대에 설치하고, 진료실·접수실 PC는 프로그램만 설치합니다.

엑셀·CSV로 자료 옮기기

지금 차트 회사에 자료 내보내기(엑셀·CSV)를 요청하고, 받은 파일을 Vetchart.ai 앱에 올리면 병원 PC 안에서 바로 옮겨집니다. 기존 차트는 그대로 둡니다.

엑셀로 못 내보낼 때만

구조 추출 프로그램으로 DB 구조만 뽑아 제출해 주시면 그 차트의 변환기를 만들어 드립니다. 차트 내용은 절대 넣지 마세요.

베타 참여 신청하기

신청 양식(구글폼)은 곧 열립니다. 신청 양식은 구글폼으로 열립니다. 신청서의 정보는 베타 참여 확인과 연락에만 씁니다.

자료 옮기기 — 엑셀·CSV가 먼저입니다

진료 기록은 병원의 것입니다. 옮기는 일은 모두 병원 PC 안에서 하고, 자료가 병원 밖으로 나가지 않습니다.

1. 차트 회사에 내보내기 요청

Vetchart.ai 앱의 '내보내기 요청서'를 차트 회사에 보내면 필요한 표(보호자·동물·진료 기록·청구 항목·결제·예방접종)를 받을 수 있습니다.

2. 앱에서 바로 가져오기

받은 엑셀·CSV(zip도 가능)를 올리면 표와 칸을 자동으로 짐작하고, 검사한 뒤 한 번에 가져옵니다. 실패하면 아무것도 들어가지 않습니다.

3. 안 맞으면 문제 보고서

칸이 맞지 않는 부분은 '문제 보고서'로 알려 주세요. 실제 값 없이 칸 이름과 값의 모양만 담깁니다.

엑셀로 내보낼 수 없는 병원만 아래 구조 추출 프로그램을 쓰고, 결과 파일을 [구조 파일 제출] 양식으로 올려 주세요. 제출하는 것은 DB 구조(표·칸 이름과 형식, 건수, 값의 모양)뿐입니다. 보호자·동물·진료 기록, 엑셀로 내보낸 자료, DB 파일 자체는 절대 제출하지 마세요.

구조 파일에 들어가는 것과 들어가지 않는 것

추출 프로그램의 소스 코드는 모두 공개되어 있습니다. 무엇을 읽고 무엇을 남기는지 직접 확인하실 수 있습니다.

들어가는 것들어가지 않는 것
DB 종류·버전, 표와 칸 이름, 칸 형식, 행 수, 표 사이 연결(키)보호자 이름·전화번호·주소·이메일
비어 있는 비율, 글 길이, 한글·영문·숫자 비율동물 이름, 진료 내용, 메모
날짜·전화번호처럼 '보이는' 비율, 형식 틀 (####-##-##, 가가가)직원·수의사 이름, 금액·날짜의 실제 값
진료 기록의 성별·종·상태처럼 짧고 자주 나오는 코드 값처방·처치·약품·백신 코드표의 내용, 드문 값, 사람·병원 이름처럼 생긴 값, 금액, 사진·파일 내용

DB 접속 비밀번호를 물어볼 수 있습니다. 그 PC에서 접속에만 쓰고 저장하거나 보내지 않습니다. 프로그램은 아무것도 혼자 보내지 않습니다 — 미리보기로 확인한 뒤 원장님이 직접 제출 양식에 올립니다.

자료 보호 원칙 — 기존 차트 회사의 권리를 존중합니다

진료 기록은 병원의 것입니다. 2026년 5월 한국동물병원협회 요청에 주요 차트 회사들도 "진료데이터 소유권은 동물병원에 있다"고 답했습니다 (관련 기사). 그와 함께, 차트 회사가 만든 자료와 프로그램은 그 회사의 것입니다. Vetchart.ai는 아래 원칙을 지킵니다.

공식 내보내기 우선

차트 회사가 제공하는 엑셀·CSV 내보내기 파일을 먼저 씁니다. 구조 추출 프로그램은 내보내기를 쓸 수 없을 때만 씁니다.

병원이 직접 실행하고 직접 제출합니다

추출 프로그램은 원장님이 병원 PC에서 직접 실행하고, 미리보기를 확인한 뒤 제출할지 직접 정합니다. 자동 전송은 없습니다.

읽기만, 우회 없음

DB를 읽기만 합니다. 차트 프로그램 파일을 분해·복제하지 않고, 차트 회사 서버에 접속하지 않으며, 비밀번호를 풀거나 보호 장치를 우회하지 않습니다. 접속은 병원이 아는 계정이나 DB 설치 기본 계정으로만, 물어본 뒤에 합니다.

코드표·목록은 가져오지 않습니다

처방·처치·약품·백신 코드표, 템플릿처럼 차트 회사가 만들었을 수 있는 자료는 표의 구조만 보고 내용은 남기지 않습니다. 미리보기에 '코드표'로 표시됩니다.

옮길 때도 진료 기록만

보호자·동물·차트·접종·수납 기록과, 그날 기록된 처치 이름·금액을 옮깁니다. 기존 차트 회사의 코드 체계는 옮기지 않고, Vetchart.ai의 기본 수가표·템플릿은 Vetchart.ai가 따로 만든 것입니다.

받은 구조 정보는 변환기에만

제출해 주신 구조 정보는 그 차트의 변환기를 만드는 데만 쓰고, 공개·판매하거나 다른 곳에 주지 않습니다. 요청하시면 지웁니다.

차트 회사 관계자분께 — 권리 침해가 걱정되는 부분이 있으면 문의 양식으로 알려 주세요. 확인한 뒤 바로 고치거나 해당 기능을 멈추겠습니다. 추출 프로그램의 소스 코드는 모두 공개되어 있습니다.

차트 구조 추출 프로그램 — 엑셀로 내보낼 수 없는 병원만

Windows용 · 설치 없이 실행 · 차트 서버 PC에서 진료가 끝난 뒤 실행해 주세요. 끝나면 바탕화면에 구조 정보 zip이 생기고, 미리보기를 확인한 뒤 제출 양식에 그 파일 하나만 올립니다.

※ 차트 내용(보호자·동물·진료 기록)은 절대 제출하지 마세요. 구조 정보 zip에는 들어 있지 않습니다.

VetChart_Extractor.exe 받기 구조 파일 제출

서명되지 않은 프로그램이라 Windows가 경고할 수 있습니다 → [추가 정보] → [실행]. 받은 파일이 공개된 것과 같은지는 릴리스 페이지의 SHA-256으로 확인하실 수 있습니다. 제출 양식은 파일을 올리기 위해 구글 로그인이 필요합니다.

자주 묻는 질문

환자 데이터를 가져가나요?

아니요. 자료 옮기기는 병원 PC 안에서 하고, 데이터는 병원 밖으로 나가지 않습니다. 구조 추출 프로그램을 쓰는 경우에도 구조와 값의 '모양'만 제출합니다.

엑셀로 내보낼 수 있으면 추출 프로그램은 필요 없나요?

네. 엑셀·CSV 파일이 있으면 Vetchart.ai 앱에서 바로 옮깁니다. 추출 프로그램은 내보내기를 쓸 수 없는 병원만 씁니다.

지금 쓰는 차트에 문제가 생기지 않나요?

엑셀 내보내기는 차트 회사의 기능을 쓰고, 추출 프로그램은 DB를 읽기만 합니다. 다만 읽는 동안 차트가 잠깐 느려질 수 있어 진료가 끝난 뒤 실행을 권합니다.

사업자등록번호는 왜 받나요?

동물병원 개설자인지 확인하기 위해서입니다. 베타 참여 확인과 연락에만 쓰고, 베타가 끝나거나 요청하시면 지웁니다.

DB 파일 형식(확장자)을 모르겠어요

신청서에서 '모르겠음'을 고르시면 됩니다. 필요하면 확인 방법을 메일로 안내해 드립니다.

DB 비밀번호를 모르면요?

먼저 차트 회사에 엑셀·CSV 내보내기를 요청해 주세요. 차트 회사들은 협회 요청에 데이터 이관 협조를 약속했습니다. 추출 프로그램은 DB 설치 기본 계정으로 접속해 볼지 먼저 물어보고, 비밀번호를 풀거나 보호 장치를 우회하지 않습니다.

비용이 드나요?

베타 참여와 데이터 옮기기는 무료입니다.

바로 옮겨야 하나요?

아니요. 옮긴 뒤에도 기존 차트를 그대로 두고 함께 써 보시면서, 준비가 되면 옮기시면 됩니다.

어떤 차트를 지원하나요?

엑셀·CSV로 내보낼 수 있는 차트라면 어느 것이든 옮길 수 있습니다. 내보내기가 안 되면 Firebird, MS SQL Server, MySQL/MariaDB, PostgreSQL을 쓰는 차트의 구조를 읽어 변환기를 만듭니다.

개인정보 처리 안내 — 참여 신청서(구글폼)로 받는 동물병원 이름·사업자등록번호·성함·휴대폰 번호·이메일·사용 중인 차트는 베타 참여 확인과 연락에만 쓰고, 베타가 끝나거나 요청하시면 지웁니다. 구조 정보 파일에는 개인정보가 들어 있지 않습니다. 문의: 문의 양식
